# Resources

Эта папка предназначена для изображений и медиафайлов сайта.

Ниже перечислены изображения, которые были переданы в текущем сообщении и готовы к использованию:

- image-1.jpg — общий вид гаража / автомобиль в сервисе
- image-2.jpg — автомобиль с открытой дверью, общий вид кузова
- image-3.jpg — салон / работа с рулём и панелью
- image-4.jpg — кузов и капот / замена ламп, демонтаж

Чтобы использовать их на сайте, рекомендуется сохранить файлы в этой папке с именами выше или переименовать по смыслу раздела, например:

- resources/garage-1.jpg
- resources/garage-2.jpg
- resources/interior-1.jpg
- resources/lighting-1.jpg

Если понадобится, я могу сразу подключить эти картинки в `index.html` или в галерею сайта.
